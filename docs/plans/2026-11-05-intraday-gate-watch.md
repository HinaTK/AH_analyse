# DSH 盘中门控观察设计与实施计划

用户已授权执行前述方案：15分钟复核、仅变化提醒、独立存档，不自动解除正式门控。

## 行为与边界
- 观察DSH holdings中active=true且已确认持仓qty>0的ETF；不观察空仓新标的和迁移退出标的。
- 工作日市场连续交易时段取当前报价及日OHLC，用同源历史日K（截至前一交易日）加当日未收K调用现行wilder_adx与gate规则；相同日期当日K先剔除再加入，不能重复。
- 报价必须日期正确、新鲜（<=180秒）、非未来、OHLC有限正数且满足范围；历史至少65根，最后完整日须匹配上一A股交易日，前收与行情prev匹配。不满足即诊断告警，不能生成✅放行结论。
- 读取正式regime-cache.json作对照，不调用可能刷新缓存的build_gate；不改confirmed账本、holdings、正式门控、intraday-alerts。
- 首次成功观察：与正式门控同状态静默，与正式门控不同提醒。后续在盘中level/blocks_buy改变（或正式门控改变）时提醒；数字波动不重复通知。交易日切换重新比较正式门控；同状态每15分钟只存档。
- 独立存档至DSH grid-account/intraday-gate-watch/：latest.json（含观察及去重基线）和各交易日逐次快照。每个错误也存档，按错误状态去重提醒，错误不覆盖上次成功结果。恢复后状态仍未变不再刷同一提醒。
- 提醒明确区分正式收盘门控与盘中预估，标出行情时间、现价、ADX/±DI、原因；统一写「未收盘确认，正式门控未切换；不构成可执行买单」。不冒充新仓资格或完整放行。

## 接入与验证
1. 子代理独占新tools/intraday_gate_watch.py、deploy_scripts/grid_intraday_gate_watch.py、tests/test_intraday_gate_watch.py；纯夹具TDD RED→GREEN，不写真实账本不联网测试。
2. 主会话为run_and_push添加gate_watch注册，Windows独立任务AH网格-盘中门控观察：周一至五09:45起每15分钟至14:45；午休脚本静默，交易日由confirmed_calendar确认。现有任务不改。
3. 调度脚本放在deploy_scripts，支持只预览XML；注册后导出核对执行路径、间隔、时区和启用状态。人工启动闭市运行只证明调度到脚本，实际行情变化推送待下一交易时段验证。
4. 全量tests套件与当前142项3已知失败基线对比；新观察测试及路径测试全过；核对两侧真实账本与正式门控未由本功能改写。

## 实施范围
仅新增观察模块/launcher/测试/安装任务脚本，修改run_and_push注册一项。禁止改交易策略、既有门控计算、成交、费用、去重、跨链同步或Hermes任务。无需用户再次确认。
