盘前推荐逻辑创新方案
====================

一、现有盘前流水线判断
----------------------
当前盘前推荐已经具备较完整的工程流程：
- 每次运行重新扫描候选池。
- 支持全市场或有限样本覆盖状态。
- 使用趋势、量价、流动性、估值和事件等信息。
- 对重大负面事件执行P0过滤。
- 通过质量门、行业分散和防守期上限控制推荐数量。
- 正式动作以WATCH为主，并输出支撑位、止损位和失效条件。
- 热点/LLM结果主要作为报告上下文，不直接向候选池塞票。

因此，下一步创新重点不是继续增加普通技术指标，而是解决一个更贴近盘前的问题：盘前看起来较强的股票，开盘后是否真的具备可执行性。

二、最值得优先实现的创新
------------------------

1. 从单一排名改为开盘情景推荐

每只入选股票提前给出三种情景和对应动作：

- 高开并放量：允许右侧跟随。
- 平开或小幅低开：等待突破或成交确认。
- 高开低走、低开过深或跌破支撑：取消观察。

示例：
- 主情景：高开0%~3%，前15分钟成交量达到近20日同期1.5倍，可观察。
- 次情景：平开，等待突破盘前高点。
- 失效情景：低开超过2%或跌破支撑位，取消观察。

这样盘前报告不再假定开盘价格一定符合预期，而是提前准备行动路径。

2. 增加“开盘可执行分”和缺口风险分

将当前推荐分与开盘可执行性拆开。新增指标包括：
- 预期高开幅度。
- 近20日高开后的回落概率。
- 前一日涨幅是否过大。
- 消息是否已经被价格提前反映。
- 高开后是否有足够成交承接。

报告同时展示：

```text
推荐分：82
开盘可执行分：61
缺口风险：高
动作：等待确认
```

推荐分高但可执行分低的股票，只能进入观察池，不进入正式主攻列表。

3. 建立催化剂新鲜度和衰减模型

同一条消息在首次出现和连续传播几天后的交易价值不同。建议按时间和价格反应衰减：

- 当天新公告：权重最高。
- 过去1~2天消息：中等权重。
- 一周前旧消息：只作为背景。
- 消息发布后股价已连续上涨：降低剩余催化剂权重。

建议输出：

```text
催化剂强度：高
新鲜度：0.85
价格反应：已反映60%
剩余预期空间：中
```

4. 从“利好判断”升级为“预期差判断”

盘前真正有价值的标的，往往是消息不错但价格尚未充分反映的股票。可比较：
- 新闻情绪强度。
- 前一日及近几日涨跌幅。
- 相对行业和指数的表现。
- 成交量是否提前放大。
- 同主题其他股票是否已经先涨。

据此区分：
- 利好 + 未上涨：潜在预期差。
- 利好 + 连续大涨：可能已经兑现。
- 无明显消息 + 持续强势：趋势型机会。
- 利好 + 价格走弱：疑似利好出尽。

5. 建立主题内的龙头—跟随—补涨关系

对每个行业或热点主题识别：
- 龙头股。
- 高成交额核心股。
- 高弹性跟随股。
- 尚未上涨的补涨候选。
- 已经转弱或高位兑现的股票。

盘前输出应区分：
- 龙头确认：观察强度。
- 趋势跟随：适合右侧确认。
- 补涨候选：只允许小仓观察。
- 高位兑现：回避。

这样可以避免简单追逐前一日涨幅最高的股票。

6. 强化相对强度的持续性

不要只看单日涨跌幅，应同时计算股票相对行业和指数的：
- 1日相对强度。
- 5日相对强度。
- 20日相对强度。
- 回撤后的恢复速度。
- 市场下跌时的抗跌程度。

重点识别“昨天没有大涨，但连续几天抗跌、逐步收复失地”的股票，这类标的更适合提前布局。

7. 将盘前推荐拆成两套池

建议把输出明确拆为：

- 当前主攻：今天开盘后存在明确确认条件。
- 提前布局：未来1~3个月逻辑改善，但当天不追高。
- 等待触发：逻辑成立，但价格或成交尚未确认。
- 降级观察：有故事，但证据不足。
- 回避：出现直接证伪或高位兑现风险。

“提前布局”必须满足：慢变量改善、价格不再无序破位、没有新的P0事件；试错仓位只能是该方向最终计划仓位的一小部分。

8. 以开盘后兑现概率训练盘前模型

盘后复盘不应只看5日收益，还应记录：
- 盘前入选后是否高开。
- 高开后是否站稳。
- 前30分钟是否跑赢行业。
- 收盘是否仍然有效。
- 哪种推荐状态最容易成功。

重点统计：

```text
盘前入选 → 开盘确认概率
开盘确认 → 收盘延续概率
高开追涨 → 当日回落概率
补涨候选 → 未来5日兑现概率
```

三、建议的盘前评分结构
----------------------

```text
基础质量分
+ 趋势/相对强度分
+ 预期差分
+ 催化剂新鲜度分
+ 开盘可执行分
- 缺口风险
- 利好兑现风险
- 事件/P0风险
```

最终不只输出总分，还输出：

```text
推荐等级：等待确认
盘前逻辑：高质量趋势 + 行业催化
预期差：中
开盘可执行分：74
计划：平开至高开2%可观察
加仓：突破盘前高点且量能确认
失效：低开超过2%、跌破支撑或行业宽度转弱
```

四、推荐落地顺序
----------------

第一阶段：开盘可执行性
1. 增加情景字段：高开、平开、低开、失效。
2. 增加开盘可执行分和缺口风险分。
3. 将主攻、等待触发、提前布局、回避分开输出。

第二阶段：预期差和主题结构
4. 增加催化剂新鲜度和衰减。
5. 增加消息强度与价格反应的预期差计算。
6. 建立主题内龙头、跟随、补涨、兑现分类。
7. 强化1/5/20日相对强度和抗跌能力。

第三阶段：盘前—盘后闭环
8. 记录开盘确认、前30分钟延续和收盘结果。
9. 按推荐状态、行业、市场状态统计兑现概率。
10. 用真实兑现概率调整盘前排序和推荐等级。

五、最推荐的首个版本
--------------------

优先实现“情景推荐 + 开盘可执行分 + 预期差分”。

这三个改动最贴近盘前场景，能复用现有候选池、质量门、支撑止损和盘后复盘结构，也不依赖复杂的新模型。它们能把系统从“盘前预测哪只股票可能上涨”升级成“针对不同开盘结果预先制定行动方案”。

六、实现时的约束
----------------

1. 盘前只能使用当时已经公开且可获得的数据，不能混入盘中或收盘后的信息。
2. 高开本身不能视为强势确认，必须结合成交、相对强度和行业宽度。
3. 旧观察池、前一日名单和热点标签只能作为对照，不能自动沿用。
4. “可埋伏”必须满足慢变量改善、价格止跌或接近客观止损、无新的P0证伪，并限制试错仓位。
5. 数据覆盖不足时必须标注有限样本，不得把有限样本结果包装成全市场结论。
