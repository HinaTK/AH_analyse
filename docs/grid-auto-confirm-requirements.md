# 成交日期与ID自动化验收

用户确认：日期默认按发送成交信息的北京时间日期；成交ID沿各ETF现有序列递增，用户不需要提供编号。

- 聊天适配层传入收到原消息的时间戳，处理跨午夜时不得改成处理日期。
- 裸CLI没有原聊天消息元数据；默认入口接收时间，来源必须明确，不假装知道用户发送时间。可传received-at固定重试日期。
- ID在状态锁内生成，不能在外部临时计算；按ETF独立递增且不撞现有ID。
- 用原消息身份及条目序号做重试幂等；不是按价格/数量去重，两个独立消息相同成交仍是独立记录。
- 日期与ID可明确覆盖兼容老接口；无成交方向数量价格时不能整票推断。
- 真实历史保留，禁止测试在生产子账新增模拟成交。
- 临时home实际部署确认CLI测试、并发及同消息重试、不同消息同价量、历史日期未知、重复格配对均需覆盖。
- 日期乱序或未来应拒绝而非静默修正。
