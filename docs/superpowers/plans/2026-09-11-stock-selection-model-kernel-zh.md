# 选股模型内核方案（中文）

日期：2026-09-11
对应执行清单：docs/superpowers/plans/2026-09-11-stock-selection-model-kernel.md
状态：方案已定，代码未改。正式盘前报告仍走现行六维逻辑。

## 一句话

不要推翻盘前流水线。要换的是选股内核：短名单标签和六维手工加权都不再当排名答案。外壳留下，排序换成可交易全截面加滚动训练的排序模型，打不过现行六维就不切换。

## 你要打造的是什么

你要的是选股模型，不是盘前观察打分器。

选股模型回答的是：在信号日能看到的信息里，哪些股票在未来几天相对沪深300更可能走强。它必须能空仓，必须能被证伪，必须用后来发生的收益检验。

现行系统回答的是：今天哪些票看起来像强势、证据够不够、能不能推。这套防伪壳有价值，但六维加权和标签短名单都不是选股答案。

## 明确不推倒的部分

08:30 盘前作业、全市场采集、覆盖率诚实、P0 否决、质量门失败清空、行业分散、防守期最多 2 只、正式动作只有 WATCH、飞书微信推送、ETF 0-3 只，全部保留。

LLM 热点仍然只能当报告上下文，不能往候选池里塞票。昨天的观察池不能自动变成今天的股票池。

## 两个标签不要混

短名单标签，例如领涨、放量、新高、抗跌、龙虎榜、重点行业。这是另一层手工筛选，和六维打分是一类东西。选股内核里它不再当门、不加分、不排序。最多作为旁路记录，方便以后对照打标签和不打标签差在哪。

训练标签，是模型的对错标准：信号日后 T+1 开盘到 T+5 收盘，相对沪深300 的可成交超额收益。这个必须有。没有它，模型没有对错。

行业归属只做出处，不加分，不当入场券。

## 现行流水线在干什么

工作日 08:30，run.py 大致是：全市场快照；scan_snapshot 打短名单标签，没标签就丢弃，按标签个数截到大约 600 只；硬过滤后六维加权打分截 30 只；补日线和证据再打一遍；LLM 只改消息维；风险降级；select_by_rules 产出 0-5 只 WATCH；质量门失败则股票和 ETF 都清空。

六维默认权重写在 candidate_pool.py：趋势 0.25、量价 0.20、估值质量 0.15、资金 0.15、相对强度 0.15、消息 0.10，外加风险惩罚。缺数据记 0（没有相关新闻时消息维记 0.5）。门槛 0.55。factor_weights.json 仍是旧三因子，键对不上就回退这套默认。

rolling_calibration.py 已经有 purged walk-forward，但线上排序没用它，只是在六维权重上最多挪 0.05。所以今天经常空仓，很多时候是防伪门在工作，不是模型在选股。

## 目标形态

全市场快照 -> 只做可交易预筛（代码有效、价格有效、非 ST、成交额够）-> 全截面进模型打分 -> 硬过滤 / P0 / 质量门 / 行业分散 / 防守限额 -> 0-N 只 WATCH。

模型分替代六维综合分，成为正式排序键。六维分数留下来当解释，不当排名答案。质量门失败仍清空。模型无效时不准偷偷退回感觉还能用的固定权重，只能继续用旧键并写明原因，或者空仓。

可交易预筛：6 位代码、价格大于 0、名称不含 ST / 退 / 暂停 / B股、成交额至少 1 亿元。过了这些，即使今天没领涨、没放量、没新高，也要进截面。

## 分七步做

第 1 步：关掉短名单门。改 scan_snapshot。启发式标签写到旁路字段 source_tags_sidecar，空标签不再丢票，不再按标签个数排序，改为按成交额排序。run.py 默认不再截成 600 只标签池。池子变大是故意的。

第 2 步：截面变换，缺值保持缺。新建截面 rank / zscore。某只股票缺 PE、缺动量，这一维就是空，不填 0 再拿去排序。

第 3 步：每天存影子面板，正式推荐先不动。每天把全部可交易票的点时特征存成面板，和正式 30 只报告卡分开。正式 picks 暂时仍走六维综合分。mock 面板以后不准拿来晋级线上模型。

第 4 步：给面板打训练标签。信号日 D0 只用当天及以前能看到的信息；买入日为之后第一个交易日开盘；观察到买入后再第 5 个交易日收盘；收益用现有成交约束算净收益再减同期沪深300；停牌买不进就是未成交；标签还没走完的截面不准进训练集；谁在不在样本里由信号日决定。

第 5 步：上排序器，先线性。用现有六维当点时特征，先上线性 / 岭回归排序。LightGBM 排序只有能 import 才作为可选项。不要一上来深度网络，也不要先去接 Qlib Alpha158。缺特征就不出分。

第 6 步：晋级门，线上开关默认关。把 rolling_calibration.py 从微调六维权重扩成滚动训练排序器，和现行 0.55 六维比。只有实盘点时、全可交易截面、purged 至少 3 个 fold、最新测试窗超额稳定更好、回撤不明显更差，才允许把线上排序键改成模型分。打不过就维持 composite 并写明原因。

第 7 步：解释仍走证据。入选理由继续用趋势、量价、质量等证据语句。不能把有 4 个标签写成推荐原因。空仓继续合法。覆盖率里的候选数量改成可交易预筛规模。

## 和参考仓、网上经验的关系

本机已对源码的仓没有一套和我们相同的六维打分。stock-screener 是 Minervini 规则筛；daily_stock_analysis / alphasift 是策略模板或单票趋势量能；alphaevo 是 LLM 合成因子；qlib 是特征集加模型 IC/ICIR。

网上共识：固定权重会因 IC 衰减失效；截面排序优于绝对阈值；验证要用 purged / embargo。我们真正的优势在盘前工程：覆盖率降级、P0、质量门、接受空仓。劣势是内核还是观察打分器。Qlib / Alpha158 是以后的增强，不是这一期门槛。

## 成功标准

软件成功：短名单不再决定谁能进池；影子面板每天落地；测试能拦住缺值填 0、mock 面板晋级、标签池冒充全截面。

研究成功：至少 3 个未触碰测试窗，超额稳定好于现行六维，才切换线上排序键。

投资成功：本方案不承诺。合成夹具和短样本都不能拿来宣称有 alpha。

## 不在这一期做的事

不重写采集、推送、ETF、P0、质量门。不把 Qlib 装成运行时依赖。不让 LLM 往池子里加股票。不把缺 PE / 缺动量填成 0.5 中性质量。不覆盖当日 latest.json，测试不准发推送。

## 建议的执行顺序

先做第 1 步和第 3 步：池子改对，样本开始攒。第 2、4、5 步可以在影子模式里准备。第 6 步必须等实盘面板够长。第 7 步是文案和解释。
