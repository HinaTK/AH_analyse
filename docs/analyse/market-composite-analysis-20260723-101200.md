- 今日盘中主线是资源/能源扰动 + 电力设备/电网 + AI硬件/元件，而不是半导体或纯港股科技。

- 半导体或恒生科技若午后放量翻红并跑赢大盘，当前“降级观察”判断会失效。

- 若电力设备/有色只是早盘脉冲，午后没有成交延续，则不应升级为中期主线。
