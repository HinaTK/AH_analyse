## 2. 结论摘要
今天A股市场呈现极端强势与结构性轮动并存的特征，上证指数突破4200点，创下逾10年新高。

与此同时，在风险偏好全面提升的背景下，资金从**黄金、海运、银行等防御及传统周期板块**流出，形成明显的抽血效应。
