## 七项当前落地

1. `factor_validation.py`：按日横截面计算 Rank IC、相关性；常量/缺失不能伪造零 IC。原先把自身涨幅再包装为相对强度的重复加分已移除，真正 RS 需要同日期基准。
2. `financial_data.py`、`quality_factors.py`：ROE、增长、现金转换、负债率；年报口径、单位、各字段发布日期与来源。金融行业不套用一般工业企业的杠杆/现金流阈值。流水线财务富集上限 30 个扫描候选，明确是子集，不能说全市场财务覆盖。
3. `rolling_calibration.py`：每折训练 IC 拟合，验证集选有限权重/阈值，测试只评估。标签重叠 purging；测试退出延迟不得删除亏损样本。合成数据只检验程序，不能晋级真实权重。
4. `portfolio_validation.py`：不重叠、等资金槽位组合，现金保留、逐日收盘净值/回撤、换手、同期基准及分环境结果。该模型不等于指定账户金额下的完整整手交易模拟，也不是日内最坏回撤。
5. `execution_validation.py`、`execution_data.py`：下一交易日开盘、T+1、实际执行日停牌/涨跌停、买卖佣金、最低佣金、卖出税费、滑点；缺失不伪造成交，退出障碍延迟。未处理的分红除权持仓拒绝结果，避免把除权缺口当亏损。固定持有期评估不等于 WATCH 触发策略。
6. `market_factors.py`、`rule_selector.py`：已完成交易日基准 MA20/MA60/斜率；防守/未知状态拦截正式选股；过期基准不算可用。报告披露基准日期、来源、因子覆盖。
7. `reweight.py`：完整候选面板、同版本、足够折数/样本、稳定净超额、每日组合风险、单权重调整≤0.05、同一证据不能重复晋级；旧预览胜率不再直接驱动生产权重。
