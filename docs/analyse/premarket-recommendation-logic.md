# 盘前推荐的逻辑

## 定位

盘前推荐不是预测“今天一定涨什么”，而是根据隔夜信息和开盘后可验证的条件，制定一套“优先观察什么、什么情况下可以进攻”的计划。

## 1. 先判断市场环境

盘前先检查：

- A 股、港股主要指数及近期趋势；
- 隔夜美股、美元、人民币、利率、商品等外部变量；
- 市场宽度、成交量和风险偏好；
- 政策、宏观数据、业绩或行业事件。

据此形成三种姿态：

- **进攻**：指数、成交和领涨方向较同步；
- **防守**：指数偏弱，热点快速轮动；
- **等待**：信号冲突或证据不足。

盘前只描述情景和开盘后的确认条件，不能把尚未发生的盘中走势写成事实。

## 2. 筛选“有催化且有价格确认”的方向

行业不能只因为有新闻就推荐，还要同时检查：

- 是否存在政策、订单、业绩、供需或产业催化；
- 行业是否跑赢大盘；
- 是否有成交量和市场宽度支持；
- 龙头是否真正走强，而非少数股票孤立上涨；
- ETF 或指数是否同步确认。

原则是：**价格确认优先于故事**。有利好但价格、成交和相对强度不配合，只标记为“需确认”或“降级观察”。

## 3. ETF 优先，个股作为观察标的

盘前先给行业或 ETF 方向，再给个股观察池。个股池每次动态重建，扫描：

- 当次领涨股；
- 放量股；
- 阶段新高股；
- 抗跌股；
- 有利好但暂时不涨的股票。

再按相对强度、成交确认、日内位置、催化与价格一致性、行业代表性排序，选出约 4—6 只。个股可分别承担以下角色：

- **龙头**：验证主线强度；
- **弹性**：观察进攻空间；
- **验证**：确认行业逻辑是否扩散；
- **防御**：市场转弱时观察；
- **避雷**：验证“利好不涨”是否意味着资金不认可。

因此，个股池是有角色、有触发条件、有失效条件的观察池，不是无条件买入清单。

## 4. 按时间层级分层

- **当前主攻**：适用于当天或 T+1，必须等开盘后的强弱和成交确认；
- **未来 1—3 个月主投**：看产业趋势、政策、订单和盈利等慢变量；
- **可小仓底仓 / 可埋伏**：只有在中期逻辑改善、价格不再无序破位、没有重大证伪事件时才成立；
- **等待触发 / 降级观察**：逻辑尚可，但趋势、成交或催化尚未确认；
- **回避 / 撤退**：价格结构或核心逻辑已经被否定。

“可埋伏”不能仅因为跌幅大、估值低或故事合理就成立，还必须给出：

- 试错仓上限：目标方向最终计划仓位的 10%—30%；
- 右侧确认加仓条件；
- 减仓、止损或退出条件。

## 5. 形成条件式行动建议

每个方向都要回答：

- 能不能追高；
- 是否等回踩；
- 什么信号出现后才能加仓；
- 什么情况下减仓或退出；
- 何时从“等待”切换为“进攻”；
- 何时从“进攻”降级为“防守”。

简化决策树：

```text
指数强 + 成交确认 + 主线领涨
    → 可进攻，ETF 优先，回踩确认后参与

指数强但主线分化，或成交不足
    → 等待，不追高，只观察触发条件

指数弱 + 热点轮动快
    → 防守，降低仓位，避免扩大弱线

催化存在但价格不涨
    → 降级观察，不能仅凭新闻买入
```

## 6. 推荐结论的状态标签

每个重大结论都要带状态和边界：

- **有效**：当前证据支持，给出适用时间窗口；
- **需确认**：方向合理，但需等待开盘价格、成交或相对强度确认；
- **降级观察**：逻辑仍在，但价格结构或资金确认不足；
- **已失效**：关键价格、事件或行业逻辑被否定。

同时写清楚失效信号，例如跌破关键支撑、成交无法放大、主线宽度收缩、利好兑现后不涨，或出现新的重大负面事件。

## 一句话总结

盘前推荐的顺序是：**先判断环境，再筛选主线；先验证价格和成交，再谈催化；先给 ETF 和观察池，再给个股；所有结论都附带状态、有效窗口和失效信号。**

本文件解释的是方法论，不代表任何具体交易日的实时推荐，也不构成个性化投资建议。
