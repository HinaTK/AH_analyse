## 问题摘要

本次错误不是事件识别错误，而是执行层级表达错误。

盘前识别到的创新药催化包括：信达生物与辉瑞合作、ASCO 2026窗口、5月官方PMI中医药行业产需活跃。这些证据可以支持`事件雷达`和`1-3个月候选`，但不能在开盘前直接表达为可执行的`当前主攻`。

## 错误根因

1. 将`事件催化强`和`价格确认强`混在一起，导致措辞偏乐观。
2. 盘前结论虽然附带`开盘后30-60分钟确认`条件，但最终表达没有把它降级成`等待确认`。
3. A/H证据分裂时，没有强制拆开写，导致港股创新药的强度被错误外推到A股创新药和医疗整体。
4. 最终聊天中没有强制输出`价格确认状态`，用户看到的是方向结论，而不是可执行等级。

## 后续执行口径

以后盘前/盘中分析必须按以下顺序给结论：

1. 先写事件催化：有什么逻辑。
2. 再写价格确认：ETF/指数是否跑赢基准。
3. 再写执行等级：`当前主攻 / 右侧确认加仓 / 可小仓底仓 / 等待触发 / 降级观察 / 回避撤退`。
4. 如果价格未确认，默认表达为`有催化，等待价格确认`，不能写`有戏`。
5. 如果价格反向，表达为`盘前假设未确认 / 降级观察`。
6. 如果A/H分裂，表达为`港股确认，A股未确认`或相反，不能合并成整体行业结论。
