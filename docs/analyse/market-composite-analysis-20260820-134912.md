1. **医药主线从个股扩散到板块。** AkShare行业前列覆盖疫苗、诊断服务、生物制品、CRO、医疗研发外包等，多个板块上涨家数明显占优；沃森生物、博腾股份、智飞生物、近岸蛋白等出现涨停/接近涨停。价格、板块宽度和成交同时出现，盘中主线成立，但仍不能升级为1-3个月主投。
2. **黄金/资源是第二强线。** 518880黄金ETF+2.59%，紫金矿业+4.52%、成交约120亿元；商品与价格一致，但涨幅较大，采取“不追、等回踩”。
3. **科技仅局部抗跌，不是修复主线。** 新易盛基本持平、长电科技+2.59%，但科创50-0.71%、半导体设备ETF-0.27%、芯片ETF-0.63%；不能用两只个股抗跌替代ETF确认。
4. **煤炭/焦炭出现个股与板块背离。** 宝泰隆+7.24%，但焦炭板块-2.61%、仅1家上涨；这是个股事件/资金集中，不是行业宽度确认。
