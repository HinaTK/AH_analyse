# 网格汇总口径与交易日计数（2026-10-20 用户两次纠正后固化）

## 合计必须包含的字段

用户两次指出「合计那里漏了交易天数和净投入」。任何逐持仓汇总的**合计**区块，缺一即视为不完整：

| 字段 | 说明 |
|---|---|
| 交易区间 | 起止日期，例如 2026-09-23 → 2026-10-20 |
| 自然日 | 区间内全部天数 |
| **交易日** | **按 A 股实际休市扣除后的交易日数** |
| 成交总笔数 | 买／卖分别计数 |
| 买入金额合计 | 不含佣金的买入成交额 |
| 卖出金额合计 | 不含佣金的卖出成交额 |
| 佣金合计 | 按本地估算（万一、每笔最低1元） |
| **净投入合计** | 买入含费 − 卖出含费 |
| 持有份额合计 | 三只 ETF 份额之和 |
| 做T总轮数 | 已完成做T笔数 |
| 做T毛利合计 | 不含费价差 |
| 做T双边佣金 | 每轮买入+卖出各1元 |
| **做T净利合计** | 毛利 − 双边佣金 |

## 交易日计数：必须扣 A 股法定节假日，不能只扣周末

**2026-10-20 实测错误**：把 2026-09-23 → 2026-10-16 算成 **18 个交易日**，实际只有 **11 天**。原因：只按 `weekday() < 5` 过滤，没扣中秋和国庆。

2026 年 A 股休市（来源：国务院办公厅节假日安排 + 上交所休市安排）：
- **中秋节**：9月25日（周五）至 9月27日（周日）休市，9月28日（周一）开市
- **国庆节**：10月1日（周四）至 10月7日（周三）休市，10月8日（周四）开市
- **10月10日（周六）**：补班日，股市不开市

计算规则：`weekday() < 5` **且** 不在上述休市集合内，才算交易日。补班日（周六/周日上班）股市仍休市，不能算。

**教训**：任何涉及「交易日／交易天数」的汇总，先查当年交易所休市安排再算。不要用自然日或未扣假期的工作日冒充交易日。

## 逐持仓必须包含的字段

每只 ETF 至少：成交笔数（买／卖）、持有份额、可卖份额（T+1池）、最大格序号、净投入、加权单位成本（若有）、做T轮数、做T净利。

## 做T明细的展示规则

- 按 ETF 分组，每轮一行：格、买入ID、卖出ID、份额、买入价、卖出价、毛利、双边费、净利。
- 同格反复做T（如 E 格3轮、D 格2轮）必须按**成交ID**独立配对，不能按格去重或交叉匹配。
- 做T记录中**没有日期字段**时不要编造；轮次顺序来自 `t_records` 存储顺序，不等于时间顺序，需明确说明。

## 与净投入相关的关键区分

- **净投入 = 累计净现金流出**（买入含费 − 卖出含费），**不是当前时点的占用金额**。它可能超过账户授权线。
- 真实当前占用 = 持有份额 × 当前市值 − 已回笼现金，需结合实时行情和可用现金另算，且尚未与券商对账时不能当作已知。
- **做T净利是已实现价差，不含未平仓库存浮盈浮亏**。若要给「总盈亏」，公式是市值 − 净投入，**不要再加一次做T净利**（做T净利已包含在净投入的变动中）。

## 总账户盈亏的唯一公式与入金分母（2026-10-22 双重计算错误固化）

**错误实录**：汇报时写了「浮亏 −9,879.60 + 做T净利 +2,129 = 总盈亏 −7,750.60」，被用户用独立复核（GLM）抓到。错因：净投入本身 = 累计买入 − **全部**卖出（含T轮卖单），做T利润已经通过卖出回笼反映在净投入里；再叠一次就是双重计算。正确分解：

| 项目 | 公式 |
|---|---|
| 未平仓 lot 真实成本 | 各未卖 lot（qty×price+佣金）之和 |
| 纯持仓浮亏 | 市值 − 未平仓 lot 成本 |
| 做T已实现净利 | t_records 净利合计（平行展示） |
| **总账盈亏** | **市值 − 净投入**（唯一公式，算一次） |
| 交叉验证 | 市值 + 现金 − 累计入金 = 同一值；两边不等必有错 |

- 已落地 `grid_summary.account_total_pnl()`（提交 c1645bb，t_net_added=False 字段结构性禁止叠加）。
- **入金分母**：用户可能中途加钱（本例 10 万本金 + 迁移期补入 2 万 = 120,000）。汇报年化/百分比前先确认累计入金；现金流反推法（现金不能为负）可验证分母。分母错了，百分比全错。
- **汇报层错误比代码层更常见**：代码输出对了，聊天里手写公式仍可能叠错。任何总盈亏数字出口前，用「市值+现金−入金」恒等式自查一遍。

## 账本日期不确定性的表述

账本里有明确日期的成交可能只有最近几天（早期成交按用户要求保留 `null`）。因此「N 个交易日」不能说成「每天都有成交」，必须另起一行说明有明确日期的成交分布在哪些天。

## 费用口径

佣金按万一、每笔最低 1 元本地估算，买入卖出各计 1 元。**不是券商实际交割费用**，需在汇总末尾标注。
